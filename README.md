# RAV Vast — тренажёр

Веб-приложение для игры и разучивания композиций на RAV Vast (строй E Low Pygmy).
Слушает настоящий инструмент через микрофон, узнаёт, по какому полю ударили,
и оценивает тайминг и качество звука.

**Открыть:** https://stenel.github.io/ravvast-trainer/

## Установка на телефон

Приложение ставится как обычное приложение, без магазина:

- **Android, Chrome:** меню «⋮» → «Установить приложение» (или «Добавить на главный экран»).
- **iPhone, Safari:** «Поделиться» → «На экран „Домой“».

После первого открытия работает без сети. Экран во время игры не гаснет.
Прогресс и калибровка хранятся в браузере конкретного устройства.

## Как пользоваться микрофоном

1. На главной выберите «Микрофон» и разрешите доступ.
2. «Калибровка»: коснитесь поля на схеме, ударьте по нему на инструменте три раза,
   приглушая ладонью между ударами. Откалиброванные поля обводятся зелёным.
3. «Свободная игра» показывает, какое поле услышано, и строку диагностики.
4. Если ловит лишнее — чувствительность «низкая»; если пропускает тихие удары — «высокая».

Положите телефон рядом с инструментом. Обработка голоса (шумоподавление, эхоподавление)
отключается приложением; Bluetooth-гарнитуры дают большую задержку.

## Разработка

```bash
npm install
npm run dev      # локальный сервер
npm test         # тесты (Vitest)
npm run build    # сборка в dist/
```

Каждый push в `master` запускает тесты и публикует сайт на GitHub Pages.

- `scales/*.json` — строи: ноты, расположение полей (`angle` — градусы по часовой стрелке
  от дальней от игрока точки), измеренный спектр поля (`partials`).
- `compositions/*.json` — композиции: `title`, `scale`, `bpm`, необязательный `level` (1–3)
  и `notes` с полями `tongue` (номер поля, 0 — центр), `beat` и `duration` в долях.
- `src/core` — логика без DOM (распознавание, оценка, разбор файлов), покрыта тестами.
- `src/audio`, `src/ui` — микрофон, синтезатор, экраны.

### Диагностика распознавания

В «Свободной игре» кнопка «Записать 15 с для диагностики» сохраняет WAV с сырым звуком
микрофона. Разбор записи:

```powershell
$env:WAV='путь\к\файлу.wav'; $env:OUT='report.txt'; npx vitest run tests/analyze-wav.test.ts
```

Записи кладутся в `samples/` — эта папка не входит в репозиторий.
